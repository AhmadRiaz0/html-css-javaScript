🍽️ Omnifood
Omnifood is a modern responsive landing page for a fictional AI-powered food subscription service that delivers healthy meals to customers every day.

The goal of this project was to practice modern front-end development techniques, including responsive design, CSS layouts, performance optimization, and interactive JavaScript components.

Overview
Omnifood is a landing page designed to promote a food subscription service powered by AI.

The website presents:

- How the service works
- Meal examples
- Customer testimonials
- Pricing plans
- A call-to-action section with a signup form

The layout adapts to different screen sizes, ensuring a smooth user experience on desktop, tablet, and mobile devices

Technologies Used :

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Flexbox
- CSS Grid
- IntersectionObserver API
- Responsive Design
- Web Performance Optimization
