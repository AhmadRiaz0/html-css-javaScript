Natours Project
Natours is a modern and responsive website project focused on nature tours and outdoor experiences.
It was built as part of an advanced CSS learning process to practice layout design, animations, and scalable styling.

Overview
This project demonstrates a complete CSS workflow, from writing maintainable styles using Sass to optimizing the final CSS for production.
It includes responsive design, reusable components, and performance optimization techniques.
