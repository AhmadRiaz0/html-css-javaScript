GuessTheNumber
JavaScript application where the player must guess a randomly generated number between 1 and 20.

Features:
Generate a random secret number

Display hints: "Too high" or "Too low"

Track and update the score with each guess

Store and display the high score

Reset the game with the "Again" button

Visual feedback on win (color + size change)

Technologies Used:
Language: JavaScript

UI: HTML, CSS

Editor: Visual Studio Code

Tools: Live Server (optional for local testing)
