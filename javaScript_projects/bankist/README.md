Bankist App
Bankist is a JavaScript banking simulation app that allows users to log in, view their transactions, transfer money, request loans, and manage their accounts.

Features
Secure login system using username and PIN
Dynamic transaction list showing deposits and withdrawals with smart date formatting (Today, Yesterday, x days ago)
Automatic currency and number formatting based on user locale (Intl.NumberFormat)
Real-time balance, income, and interest calculation
Money transfer system between accounts
Loan request feature with eligibility check
Account closure functionality (Delete user)
Transaction sorting (ascending/descending order)
Auto logout timer after user inactivity (setInterval, clearInterval)
Use of modern JavaScript APIs (Intl.DateTimeFormat, Intl.NumberFormat, Date API)

Technologies Used
Language: JavaScript (ES6+)
UI: HTML, CSS
Editor: Visual Studio Code
Tools: Live Server (for local testing)
