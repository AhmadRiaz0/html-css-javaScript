Modern Interactive Landing Page
Modern landing page built with HTML, CSS, and JavaScript. It demonstrates various interactive UI components including a modal window, smooth scrolling, tabbed content, sticky navigation, lazy-loaded images, and a slider/carousel. The design is responsive-ready and can be further enhanced for mobile devices.

Features :

1. Modal Window
   Open and close modal with buttons.
   Close modal by clicking the overlay or pressing the Escape key.

2. Smooth Scrolling
   Scroll to sections smoothly when clicking navigation links or buttons.

3. Tabbed Component
   Switch between different content sections using tabs.
   Only the active tab content is visible.

4. Navigation Fade Animation
   Menu links fade on hover to improve focus on the active link.
   Logo opacity adjusts along with the menu items.

5. Sticky Navigation
   Navigation bar sticks to the top of the page when scrolling past the header.
   Implemented using the Intersection Observer API for performance.

6. Section Reveal on Scroll
   Sections animate into view as the user scrolls down.
   Lazy revealing for better UX and performance.

7. Lazy Loading Images
   Images with data-src load only when they enter the viewport.
   Low-resolution images initially blurred for better performance.

8. Slider / Carousel
   Fully functional image slider with:
   Left and right navigation arrows
   Dot indicators for each slide
   Keyboard arrow support
   Smooth transitions between slides
   Active slide and dot always in sync.

Technologies Used :
HTML5 – Semantic structure
CSS3 – Flexbox, Grid, custom properties, transitions
JavaScript (ES6) – DOM manipulation, event handling, Intersection Observer API
Editor: Visual Studio Code
Tools: Live Server (for local testing)
