ModalPopupJS
JavaScript project that displays a modal popup window when a button is clicked. The modal can be closed by clicking outside, on the close button, or by pressing the Escape key.

Features:
Open a modal window on button click

Close modal via close button, overlay click, or Escape key

Uses class manipulation to show/hide modal

Supports multiple modal trigger buttons

Technologies Used:
Language: JavaScript

UI: HTML, CSS

Editor: Visual Studio Code

Tools: Live Server (optional for local preview)
